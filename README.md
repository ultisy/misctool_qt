# PC방 회원 관리 프로그램 - “PCMAM”

## 개요

이 프로젝트는 C++ 언어를 사용하는 Qt 프레임워크를 이용하여 구현한 간단한 프로그램이다. **PC방을 운영하는 매니저 입장에서 고객(회원)들의 정보를 관리하는 기능**을 가지고 있다.

## 기능

- 회원 정보(이름, 사용자 아이디 및 비밀번호, 잔여 금액, 신상정보 등)를 저장, 제거하는 기능
- 회원 정보를 `.json` 형태로 내보내거나 불러오는 기능
- 불러져 있는 회원 정보를 검색하는 기능

## 요구 사항

- MS Windows 11
- **Qt 6.10.2** (-해당 환경에서 개발되었으며, QTCreator로 빌드하여야 함.)
